# Robodog harness & use cases

This organisation is the home of the development and research around robodogs.

There is an [core poject](https://github.com/hse-deb-robodog/robodog-core) setting up the base functionality, a [node-sdk](https://github.com/hse-deb-robodog/robodog-sdk), and [type system for zenoh messages](https://github.com/hse-deb-robodog/zenode).
